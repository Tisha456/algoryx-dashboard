# Algoryx Week 2 – Scroll-Based Animated Landing Page

A modern, responsive landing page developed as part of the Algoryx Week 2 task. The project focuses on smooth scrolling, engaging animations, responsive design, and a clean user experience.

## 🚀 Live Demo

https://algoryx-week2.vercel.app

## 📂 GitHub Repository

https://github.com/Tisha456/algoryx-dashboard

## 🎯 Objective

To create a modern landing page with smooth scrolling, engaging animations, responsive layouts, and interactive UI components using React and modern frontend technologies.

## ✨ Features

- Responsive navigation bar
- Mobile hamburger menu
- Animated hero section
- Smooth scrolling navigation
- Scroll reveal animations
- Animated service cards
- Interactive hover effects
- Process timeline
- Testimonials section
- Validated contact form
- Dark/Light theme toggle
- Scroll progress indicator
- Responsive mobile and desktop design

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- Lucide React
- HTML5
- CSS3
